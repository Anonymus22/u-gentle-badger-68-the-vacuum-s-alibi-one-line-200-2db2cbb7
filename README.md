A make.fun micro bounty entry: the funniest one-line excuse a robot vacuum
gives for missing a spot, in 200 characters or fewer.

## The entry

> My lidar mapped that corner as a demilitarized zone after the cat declared it sovereign territory, so I respected the treaty and vacuumed around it.

## Run it

```sh
node main.ts
```

This writes the single line to `/output/entry.txt` (no trailing newline).
Node 22, standard library only, no dependencies.
